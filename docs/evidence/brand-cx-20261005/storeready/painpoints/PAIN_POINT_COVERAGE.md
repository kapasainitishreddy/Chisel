# Pain-point Coverage

StoreReady treats unknown external evidence as **AUTOMATION_PENDING**, not PASS. Future rules stay advisory until their effective date.

| Module | Status | Pain point covered |
| --- | --- | --- |
| Google Production Access | AUTOMATION_PENDING | Closed-test and production-access evidence |
| Android Developer Verification | AUTOMATION_PENDING | Identity, package and signing-key registration |
| Policy Change Watch | AUTOMATION_PENDING | Versioned policy source and effective-date tracking |
| Store Rejection Analyzer | AUTOMATION_PENDING | Translate reviewer text into scoped engineering work |
| Resubmission Pack | AUTOMATION_PENDING | Preserve fixes, evidence and reviewer notes |
| Store Declaration Reconciliation | AUTOMATION_PENDING | Catch code/runtime versus console declaration mismatches |
| Release Build Quality Gate | AUTOMATION_PENDING | Verify the actual release build, not only source |
| Android Technical Quality | AUTOMATION_PENDING | 16 KB, vitals, DEX optimization and restore-credentials readiness |
| Apple Submission Questionnaire | NOT_APPLICABLE | Age rating, export, accessibility and regulated feature review |
| EU DSA Trader Gate | NOT_APPLICABLE | Trader status and verified public contact evidence |
| OWASP Mobile Matrix | AUTOMATION_PENDING | Map security evidence to MASVS control groups |
| SDK Risk Intelligence | AUTOMATION_PENDING | Surface third-party SDK privacy/security/policy risk |
| Permission Necessity Analyzer | AUTOMATION_PENDING | Keep, remove or justify sensitive permissions |

| Release Regression Diff | AUTOMATION_PENDING | Compare current and previous release gates |
| Portfolio Risk Board | AUTOMATION_PENDING | Summarize release risk across many apps |
| Post-release Watch | AUTOMATION_PENDING | Import crash, ANR, review and policy warning signals |
| Complaint Intelligence | AUTOMATION_PENDING | Turn recurring competitor/user complaints into product evidence |
